1. Service Description

The App is a tool that helps you record important dates and set reminders in advance. Key features include:

  • Create events for important dates and choose whether to enable reminders
  • Set advance reminders 1 / 3 / 7 / 30 / 100 days ahead, delivered as local notifications
  • Display events on Home Screen widgets, Lock Screen widgets and the Dynamic Island
  • Ask Siri to look up or create events
  • Unlock more features with a Pro subscription
